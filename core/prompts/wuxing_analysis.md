# 五行分析提示词模板

## 分析目标
分析八字命局中五行的旺衰、流通、阻塞情况,为后续分析提供基础。

## 输入数据
四柱: {sizhu}
五行分布: {wuxing_data}
日主: {rizhu}

## 分析步骤

### 第一步:判断五行旺衰
根据以下标准判断各五行的旺衰状态:

**得时(季节)旺**:
- 春季(寅卯辰月): 木旺、火相、土死、金囚、水休
- 夏季(巳午未月): 火旺、土相、金死、水囚、木休
- 秋季(申酉戌月): 金旺、水相、木死、火囚、土休
- 冬季(亥子丑月): 水旺、木相、火死、土囚、金休
- 四季末(辰戌丑未月): 土旺、金相、水死、木囚、火休

**得地(位置)旺**:
- 长生十二宫: 长生、沐浴、冠带、临官、帝旺为旺
- 衰、病、死、墓、绝、胎、养为衰

**得势(帮扶)旺**:
- 天干透出同类或生扶者多
- 地支有根气,或合化为同类

**综合判断**:
- 得时+得地+得势 = 极旺
- 得时+得地 = 旺
- 得时+得势 = 较旺
- 得地+得势 = 中等
- 仅得其一 = 偏弱
- 三者皆不得 = 极弱

### 第二步:分析五行流通
检查五行之间的生克关系,判断气机是否流通:

**流通状态**:
- 五行生扶连贯,能量顺畅传递
- 生者有力,受者有根
- 断语: "气机流通,生生不息"

**阻塞状态**:
- 五行克战阻断,能量互相抵消
- 克者太旺,受者无根
- 断语: "气机阻塞,矛盾重重"

### 第三步:识别五行缺失与补救
- 列出缺失的五行
- 分析缺失五行对命局的影响
- 给出补救建议(佩戴饰品、颜色、方位等)

## 注意事项
1. 必须结合月令司权判断进气退气
2. 必须考虑合局对五行性质的影响
3. 不要简单以数量判断旺衰,要综合考虑得时、得地、得势
4. 给出的建议要具体、可操作
