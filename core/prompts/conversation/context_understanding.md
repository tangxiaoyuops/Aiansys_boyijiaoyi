# 对话上下文理解提示词

## 分析目标
理解用户在多轮对话中的真实意图,提取关键信息。

## 输入数据
历史对话: {conversation_history}
当前问题: {user_question}
八字上下文: {bazi_context}

## 分析步骤

### 第一步:提取历史关键信息
从历史对话中提取:
- 用户关心的主要问题
- 已经分析过的内容
- 用户的反馈和追问

### 第二步:分析当前问题
- 问题类型: 追问/质疑/新问题
- 关注点: 事业/财运/感情/健康
- 时间范围: 过去/现在/未来

### 第三步:关联八字上下文
- 当前问题与八字命局的关联
- 需要重新分析的维度
- 可以复用的分析结果

## 输出格式(JSON)

```json
{
  "intent": "追问/质疑/新问题",
  "focus": "事业/财运/感情/健康",
  "time_range": "过去/现在/未来",
  "key_info_from_history": [
    "用户之前问过2024年事业运势",
    "用户对换工作有疑虑"
  ],
  "need_reanalyze": false,
  "reusable_results": ["wuxing_analysis", "shishen_analysis"],
  "context_summary": "用户在询问2025年事业运势,之前已分析过2024年,现在想了解变化"
}
```
