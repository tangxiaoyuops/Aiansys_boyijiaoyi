## 🚀 使用方法

### 第一步: 启动后端API服务

```bash
# 在项目根目录
python start_agent_ui.py
```

后端服务将运行在: `http://localhost:8000`

### 第二步: 启动前端

```bash
cd frontend
npm run dev
```

### 第三步: 访问界面

打开浏览器访问您的前端地址,点击导航栏的 **"Agent框架"**

## 📖 使用步骤

### 1. 配置Agent

在界面左侧:
1. 输入 **OpenAI API Key**
2. 选择模型 (推荐 GPT-4o)
3. 点击 **"配置Agent"**

### 2. 查看工具

配置成功后,可以看到已加载的7个博弈交易工具:
- fetch_kline - 获取K线数据
- calc_indicators - 计算技术指标
- get_stock_info - 获取股票信息
- analyze_stage - 五阶段分析
- detect_washout - 洗盘识别
- analyze_distribution - 出货分析
- find_trading_points - 买卖点识别

### 3. 执行任务

在界面右侧:
1. 输入任务描述,或点击快速任务按钮
2. 设置最大迭代次数
3. 点击 **"开始分析"**

### 4. 查看结果

分析完成后会显示:
- ✅ 最终响应: Agent的分析结论
- ✅ 执行轨迹: 每一步的详细过程

## ⚠️ 注意事项

### 1. 后端服务必须先启动

前端调用的是 `http://localhost:8000/api` 的接口,所以必须先启动后端:

```bash
python start_agent_ui.py
```

### 2. 跨域问题

如果遇到跨域问题,后端已配置CORS,允许所有来源访问。

### 3. API Key安全

API Key只在前端内存中存储,刷新页面需要重新配置。

## 🔍 常见问题

### Q: 点击"配置Agent"没反应?

**A:** 检查:
1. 后端服务是否已启动
2. 浏览器控制台是否有错误
3. API Key是否有效

### Q: 分析一直转圈?

**A:** 可能原因:
1. 网络问题
2. API调用超时
3. 后端日志中有详细错误信息

查看终端的后端日志获取详细信息。

### Q: 工具列表为空?

**A:** 确认后端服务已启动,且工具加载成功。
