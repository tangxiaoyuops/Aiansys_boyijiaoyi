# 流年分析提示词模板

## 分析目标
分析流年运势、具体事件预测、吉凶判断。

## 输入数据
四柱: {sizhu}
大运数据: {dayun_data}
流年数据: {liunian_data}
日主强弱: {day_strength}
五行喜忌: {wuxing_xi_ji}

## 分析步骤

### 第一步:流年干支进入原局
**先看合**(贪合忘冲):
- 流年地支若与原局有"合局",不论冲,论"合绊"
- 合绊主"停滞、拖延、原地踏步、想动动不了"

**后看冲**:
- 流年地支冲克原局地支
- 判断冲的力量(进气之神冲退气之神,冲力大)

### 第二步:十神定位事件类型
根据流年干支引动的十神,判断事件类型:

**印星动**(遇克合):
- 培训学习、考试考证、搬家迁居、换证换章、长辈贵人、文书契约

**官星动**(遇克合):
- 升职加薪、降职撤职、调岗换部门、换领导、创业开公司、官司是非

**财星动**(遇克合):
- 赚钱获利、破财损失、父亲健康、妻子感情、投资理财、合同签约

**食伤动**(遇克合):
- 辞职跳槽、创业投资、子女晚辈、表达创作、演出表演

**比劫动**(遇克合):
- 合作合伙、竞争争夺、破财分财、朋友社交、兄弟姐妹

### 第三步:判断吉凶程度
结合五行旺衰和进气退气:

**大吉**: 喜神进气,逢生扶,无冲克
**中吉**: 喜神进气,但有轻微冲克
**小吉**: 喜神退气,但无大冲克
**小凶**: 忌神退气,但无大冲克
**中凶**: 忌神进气,但有轻微制化
**大凶**: 忌神进气,逢生扶,无制化

### 第四步:微象判断(冲克稳定器)
当流年地支冲克原局"稳定器"时:

**日主强旺**:
- 冲则动,必主大变动(搬家、换工作、破大财)
- 断语: "冲破稳定器,大变动不可避免"

**日主衰弱**:
- 冲则震,主念头、小摩擦、局部调整
- 断语: "震感强烈,建筑未倒,想动未动"

1. 必须先看合,后看冲(贪合忘冲)
2. 必须区分天干表象和地支实质
3. 必须考虑进气退气对冲克的影响
4. 微象判断要结合日主强弱
5. 事件预测要具体,有时间节点
