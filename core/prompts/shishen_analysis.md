# 十神分析提示词模板

## 分析目标
分析八字命局中十神的配置、格局高低,判断事业、财运、婚姻等方面的信息。

## 输入数据
四柱: {sizhu}
十神配置: {shishen_data}
日主强弱: {day_strength}

## 分析步骤

### 第一步:判断日主强弱
**身强判定标准**(满足以下条件之一):
1. 地支有强根(禄、刃、长生、帝旺) + 大运走印比
2. 地支有合局生扶 + 天干透印比
3. 月令虽不当令,但地支根气足 + 天干有生扶

**身弱判定标准**(满足以下条件之一):
1. 地支无根或根弱 + 大运克泄耗
2. 月令当令但被冲克 + 天干无生扶
3. 整体气势虚浮,无依无靠

### 第二步:分析十神配置
根据日主强弱,分析各十神的含义:

**身强格的十神判断**:
- 印星动(水): 印星为忌,事件=麻烦、变动、换环境、心情烦躁
- 食伤动(火): 食伤为用,事件=才华展示、创作表达、突破创新
- 财星动(土): 财星为用,事件=财运亨通、事业突破
- 官杀动(金): 官杀为用,事件=升职、掌权、事业有成
- 比劫动(木): 比劫为忌,事件=竞争激烈、破财、人际冲突

**身弱格的十神判断**:
- 印星动(水): 印星为用,事件=学习、考试、贵人相助、安稳
- 食伤动(火): 食伤为忌,事件=表达受阻、才华难展、子女操劳
- 财星动(土): 财星为忌,事件=破财、父亲健康、妻子问题
- 官杀动(金): 官杀为忌,事件=压力、疾病、是非
- 比劫动(木): 比劫为用,事件=朋友相助、合作顺利

### 第三步:判断格局
根据十神配置判断格局类型:

**正格**:
- 正印格: 月令为印,天干透印
- 偏印格: 月令为偏印,天干透偏印
- 食神格: 月令为食神,天干透食神
- 伤官格: 月令为伤官,天干透伤官
- 正财格: 月令为财,天干透财
- 偏财格: 月令为偏财,天干透偏财
- 正官格: 月令为官,天干透官
- 七杀格: 月令为七杀,天干透七杀

**从格**:
- 从强格: 日主极旺,无克泄耗
- 从弱格: 日主极弱,无生扶

**化格**:
- 化气格: 天干合化,地支有化神

### 第四步:评估格局高低
- 高格: 格局纯粹,用神有力,忌神受制
- 中格: 格局杂乱,用神有力但忌神亦强
- 低格: 格局破败,用神无力,忌神猖獗

## 注意事项
1. 必须先判断日主强弱,再分析十神
2. 身强与身弱的十神含义完全相反
3. 格局判断必须结合月令司权
4. 用神忌神的判断要准确,否则后续分析全盘皆错
